# 🚗 Controle de Frota

Sistema completo de gerenciamento de frota de veículos com sugestões inteligentes.

## 📋 Funcionalidades

### Gestão de Veículos
- ✅ Adicionar veículos à frota (placa, modelo, ano)
- ✅ Listar todos os veículos cadastrados
- ✅ Remover veículos da frota
- ✅ Armazenamento local dos dados

### 💡 Ideias e Sugestões
- ✅ **Sempre mostrando ideias** para melhorar a gestão da sua frota
- ✅ 15 sugestões práticas incluindo:
  - Manutenção preventiva
  - Rastreamento GPS
  - Controle de combustível
  - Gestão de multas
  - Treinamento de motoristas
  - E muito mais!
- ✅ Botão para carregar mais ideias progressivamente
- ✅ Reinício automático quando todas as ideias forem exibidas

### 📊 Estatísticas
- ✅ Total de veículos cadastrados
- ✅ Total de ideias exibidas
- ✅ Dashboard visual com métricas

## 🚀 Como Usar

1. **Abrir o Sistema**
   - Abra o arquivo `index.html` em qualquer navegador moderno

2. **Adicionar Veículos**
   - Preencha os campos: Placa, Modelo e Ano
   - Clique em "Adicionar Veículo"
   - O veículo aparecerá na lista

3. **Ver Ideias**
   - As ideias são exibidas automaticamente ao carregar a página
   - Clique em "Mostrar Mais Ideias" para ver sugestões adicionais
   - As ideias sempre estarão disponíveis para consulta

4. **Gerenciar Frota**
   - Visualize todos os veículos cadastrados
   - Remova veículos clicando no botão "Remover"
   - Os dados são salvos automaticamente no navegador
